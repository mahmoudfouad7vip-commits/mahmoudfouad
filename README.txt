MAHMOUD FOUAD — PERSONAL PORTFOLIO
===================================

FILES
-----
index.html  : Complete website (HTML, CSS, JavaScript are included).
profile.jpg : Your profile photo used in the homepage.

OPEN IN VISUAL STUDIO CODE
--------------------------
1. Extract this ZIP file.
2. Open Visual Studio Code.
3. Choose File > Open Folder.
4. Select the extracted folder: Mahmoud_Fouad_Portfolio.
5. Open index.html.
6. Right-click inside the editor and choose "Open with Live Server".
   If Live Server is not installed:
   - Open Extensions (Ctrl+Shift+X).
   - Search for "Live Server" by Ritwick Dey.
   - Install it, then repeat step 6.
7. The website opens in your browser. Save changes with Ctrl+S.

WITHOUT LIVE SERVER
-------------------
You can also double-click index.html to open it in Chrome or Edge.

IMPORTANT
---------
Keep profile.jpg in the same folder as index.html. The website expects
the photo filename to be exactly: profile.jpg

Some external fonts and icons load from the internet.
Replace social links or skill percentages in index.html if you want to update them.
